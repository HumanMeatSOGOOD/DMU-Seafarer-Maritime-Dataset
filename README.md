# SMN and Dualism-Attention: reproducibility package

**Anonymous version for double-anonymized review.**

This repository contains the data and code needed to inspect and reproduce the
experiments in the manuscript:

> *Dualism-Attention: A Dual-Channel Graph Attention Network for Seafarer
> Recommendation over Heterogeneous Maritime Graphs*

The package is intentionally anonymized: it contains no author names,
affiliations, e-mail addresses, or personal data. See `ANONYMITY.md` before
uploading it to GitHub.

## 1. What is included

| Path | Contents |
|---|---|
| `代码/` | Python implementation of SMN construction, Dualism-Attention, baselines, training, recommendation evaluation, table and figure generation. |
| `数据/hetero_graph_directed.pt` | The released SMN graph as a PyTorch Geometric `HeteroData` object. |
| `数据/边数据/` | The 19 anonymized part-to-whole edge tables used to build SMN. |
| `数据/节点数据/` | Anonymized identifier/category tables (`证书职务.xlsx`, `节点总表.xlsx`). No personal names are included. |
| `数据/推荐实验结果/` | The fixed 10,000-query recommendation benchmark and a readable 100-query sample. |
| `数据/*.json`, `数据/*.csv`, `数据/*.txt` | Five-seed experimental results, K-curve data, and the table rows used in the manuscript. |
| `docs/` | Dataset description, reproducibility notes, and headline results. |

## 2. SMN at a glance

- **20 node types** and **19 directed edge types**
- **23,784 nodes** and **104,571 unique edges**
- Every edge is oriented **part -> whole**; the graph is a directed acyclic graph.
- Node features are intentionally **not** stored. The code initializes
  learnable type-specific embeddings, which is the setting used in the paper.
- Node identifiers and relation identifiers are anonymized. The released data
  contain no seafarer names, vessel names, IMO numbers, or timestamps.

Detailed node/edge counts are in `数据/node_type_counts.csv`,
`数据/edge_type_counts.csv`, and `数据/dataset_summary.json`.

## 4. Environment

Tested with:

- Python 3.13
- PyTorch 2.7.1 (CPU build in our environment; CUDA builds should also work)
- PyTorch Geometric 2.6.1
- `torch-scatter` 2.1.2
- NumPy 2.3.1, pandas 2.3.0, Matplotlib 3.10.3, openpyxl 3.1.5

Install:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

For a CUDA build, install the matching PyTorch wheel first, then install
`torch-geometric` and `torch-scatter` following the PyG installation
instructions. `torch-scatter` wheels are tied to the PyTorch/CUDA/Python
combination.

## 5. Quick start (no retraining)

The five-seed results are included, so the manuscript tables and K-curves can
be regenerated without training:

```bash
python 代码/make_tables.py
python 代码/plot_all_methods_k_curves.py
```

Outputs:

- `数据/table_rows.json` (LaTeX table bodies)
- `数据/all_methods_k_curves.csv`
- `图片/all_methods_k_curves.pdf` and `.png`
- `图片/kcurve_<metric>.pdf` and `.png`

## 6. Reproducing the experiments

### 6.1 Inspect or rebuild SMN

The released graph can be loaded directly:

```python
import torch

g = torch.load("数据/hetero_graph_directed.pt", weights_only=False)
print(g)
print(g.node_types)
print(g.edge_types)
```

To rebuild the graph from the released edge tables:

```bash
python 代码/hetero_graph_directed.py
```

This writes `数据/hetero_graph_directed.pt` again. The script only uses
`数据/边数据/*.xlsx`; it does not require the raw commercial records.

### 6.2 Train one encoder

```bash
python 代码/all_edge_train.py --encoder unified_dc
```

Available encoders: `graphconv`, `graphsage`, `gat`, `film`, `gin`, `han`,
`gatv2`, `dualchannel`, `unified_dc`.

### 6.3 Full five-seed run

```bash
python 代码/multiseed_run.py
```

This trains 10 model variants (8 methods plus 2 ablation variants) over seeds
`42, 1, 2, 3, 4`, writes embeddings to `数据/节点嵌入/`, and overwrites
`数据/multiseed_results.json`. It is the most expensive step; a GPU is strongly
recommended. To keep the included result file, make a backup first.

If PyTorch deterministic mode complains on CUDA, set:

```bash
# Windows PowerShell
$env:CUBLAS_WORKSPACE_CONFIG=":4096:8"
# Linux/macOS
export CUBLAS_WORKSPACE_CONFIG=:4096:8
```

### 6.4 Recommendation benchmark (optional)

```bash
python 代码/recommendation_realistic.py
```

This regenerates the 10,000 realistic recruitment queries and evaluates any
embeddings present in `数据/节点嵌入/`. Missing methods are skipped with a
`[SKIP]` message. The fixed query file used in the paper is already included in
`数据/推荐实验结果/`, so this step is not required to reproduce the reported
recommendation numbers.

## 7. Main results

| Result | Value |
|---|---|
| All-edge link prediction, average AUC | **0.716** (4.01M parameters; 5th of 8 methods, within 0.009 of the best) |
| Core `crew -> vessel` edge, AUC | **0.840** (+14 AUC points, 20%, over the strongest baseline) |
| Recommendation at K = 10 | First on all six metrics; MaxMatch@1 **0.140**, HitRate@10 **0.104** |
| Seeds | 42, 1, 2, 3, 4 |

The exact table bodies are in `数据/table_rows.json` and
`数据/final_tables.txt`; the full per-method/per-seed records are in
`数据/multiseed_results.json` and `数据/maxmatch_results.json`.

## 8. Data and privacy

- The repository contains **anonymized, derived data only**. Raw personnel
  records, names, vessel names, IMO numbers, and timestamps are not included.
- The 19 edge tables contain only anonymized `source`/`target` identifiers.
- `节点数据/证书职务.xlsx` contains certificate/rank categories; it contains no
  personal names.
- The released graph and tables are sufficient to rebuild SMN and to inspect
  the experimental pipeline.
- Do not attempt to re-identify individuals or vessels. See `DATA_LICENSE.md`.
