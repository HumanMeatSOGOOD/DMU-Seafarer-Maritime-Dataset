# SMN dataset

## Overview

SMN (Seafarer--Maritime Network) is an anonymized heterogeneous information
network built from the business records of a maritime service provider. Every
edge is oriented from a **part** to a **whole**, so the graph is a directed
acyclic graph.

| Property | Value |
|---|---:|
| Node types | 20 |
| Directed edge types | 19 |
| Nodes | 23,784 |
| Unique edges | 104,571 |
| Edge direction | part -> whole |
| Node features in the released graph | none (type-specific embeddings are learned in code) |

The graph is stored as a PyTorch Geometric `HeteroData` object:

```python
import torch
g = torch.load("数据/hetero_graph_directed.pt", weights_only=False)
print(g)
```

`g[ntype].num_nodes` gives the number of nodes of each type, and
`g[(src, rel, dst)].edge_index` gives the directed edges of each relation.
The graph deliberately stores only topology and node counts; no names, IMO
numbers, timestamps, or free-text fields are included.

## Edge tables

`数据/边数据/` contains the 19 Excel tables used to build the graph. Each table
has only two columns, `source` and `target`, with anonymized identifiers such
as `c1`, `v1`, `pos6`. The tables preserve the original provider direction;
the build script flips the whole -> part tables (see
`代码/hetero_graph_directed.py`) so that the final graph is uniformly
part -> whole. The relation column in the table below is the **final**
part -> whole direction, not necessarily the raw column order in the file.

`数据/节点数据/证书职务.xlsx` maps certificate/rank identifiers (`pos1`, ...)
to rank names; it is needed by the recommendation query generator.
`数据/节点数据/节点总表.xlsx` lists the global anonymized node identifiers and
their type prefixes.

## Recommendation queries

`数据/推荐实验结果/realistic_queries.pt` contains 10,000 queries generated by
the rule-based simulator described in the manuscript. Each query is a list of
`(field_type, index)` pairs plus the number of valid crew. The readable sample
`realistic_queries_sample.json` contains the first 100 queries with category
labels (e.g., certificate rank). Neither file contains personal names.

## Splits and preprocessing

- Duplicate `(source, target)` records are removed, leaving 104,571 unique
  edges.
- For link prediction, edges are split into message-passing, supervised
  training, validation, and test partitions with a fixed seed; the exact
  ratios are defined in `代码/all_edge_train.py`.
- Node identifiers are categorical/anonymized; no timestamps or free-text
  attributes are used.

## Privacy and provenance

The original records are commercial and contain personal information; they are
**not** included. The released files are the anonymized graph, anonymized edge
tables, category identifiers, queries, and aggregate results. Names, vessel
names, IMO numbers, and precise timestamps were removed before release. Do not
attempt to re-identify any individual or vessel.
